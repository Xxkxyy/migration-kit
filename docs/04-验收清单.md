# 04 · 验收清单（逐项打勾）

> 建议打印出来，每完成一项签字。任何一项未过，不得进入下一阶段。

---

## 阶段 0 · 勘查

- [ ] 源端 5 台、目标端 5 台，22 端口双向可达
- [ ] 每台 root 口令验证通过（含特殊字符的逐台单测）
- [ ] 记录新旧网段、掩码、网关、DNS
- [ ] 用 `ip addr add` + `ip neigh` 实测**是否同二层**（结论写入文档）
- [ ] 记录目标端磁盘容量，确认 ≥ 源端 × 1.3

## 阶段 1 · 盘点

- [ ] 每台机器的 OS 版本、内核、时区、字符集已记录
- [ ] `df -h` / `lsblk` / 挂载点已记录
- [ ] 全部容器：名称、镜像、端口、挂载、Env、Cmd、重启策略已导出
- [ ] 全部镜像：`Repository:Tag` + `IMAGE ID` 已导出
- [ ] `ss -lntp` 与容器端口映射对照完成
- [ ] 数据库：版本、datadir、字符集、库数、表数、大表 TopN 已记录
- [ ] 账号与授权主机段已导出
- [ ] 写死 IP 的配置文件清单已生成（`grep -rl`）
- [ ] 外部依赖清单（Oracle/Redis/MQ/OSS/第三方接口）已确认

## 阶段 2 · 环境与镜像

- [ ] SELinux/RH-Firewall/时区/时间同步已处理
- [ ] 数据盘已挂载并写入 `/etc/fstab`（重启验证过）
- [ ] Docker 已安装、开机自启、存储驱动确认
- [ ] 源端镜像已全部 `save`，目标端 `load` 成功
- [ ] **两侧 IMAGE ID 逐条一致**
- [ ] `docker run --rm <image> java -version` 可执行

## 阶段 3 · 文件数据

- [ ] `rsync --dry-run` 差异规模已记录
- [ ] 实跑完成，无未重试的失败批次
- [ ] **文件数两侧相同**
- [ ] **文件字节总和两侧相同**
- [ ] 差异清单已逐条解释（如日志轮转）
- [ ] 关键目录属主/权限抽查 3 处一致

## 阶段 4 · 数据库建模

- [ ] 库数量、字符集、排序规则与源端一致
- [ ] 表数量一致
- [ ] 视图数量一致
- [ ] 存储过程/函数数量一致
- [ ] 触发器数量一致
- [ ] 账号数量、主机段已改为新网段
- [ ] 账号口令哈希与原值一致（用原口令可登录）

## 阶段 5 · 数据灌入

- [ ] 导入期参数已生效（`flush=0`、`doublewrite=0`、`O_DIRECT_NO_FSYNC`）
- [ ] 大表已完成 `DROP INDEX` → 分段并行 → `ADD INDEX`
- [ ] 所有分片 `rc=0`
- [ ] **每张大表 `COUNT(*)` 两侧相等**（列出表名与数字）
- [ ] 中等表抽样 12 张，全部一致
- [ ] 大表区间抽样 ≥ 20 点，全部命中
- [ ] **非空表统计为 0 的数量 = 0**
- [ ] 生产参数已回切：`flush=2`、`doublewrite=1`、`log_bin=1`、`stats_auto_recalc=ON`
- [ ] `mysqld` 重启后参数仍生效

## 阶段 6 · 应用重建

- [ ] 容器数量与源端一致（或多出的是源端本就没有的可选服务）
- [ ] `docker ps -a` 中 **非 Up 数量 = 0**
- [ ] 每个容器 `docker logs` 无启动致命错误
- [ ] 注册中心服务数 = 预期（列出名单）
- [ ] 中间件账号/vhost 已按业务真实值验证
- [ ] 挂载路径逐条 `ls` 确认有真实数据

## 阶段 7 · 配置改指

- [ ] 配置文件旧网段命中数 = 0（排除 `.bak_ip`）
- [ ] 容器 Env 中旧网段命中数 = 0
- [ ] 容器 Cmd 参数中旧网段命中数 = 0
- [ ] nginx `proxy_pass` 全部指向新地址
- [ ] 数据库授权主机段已更新
- [ ] 客户端配置（桌面程序/前端）已更新

## 阶段 8 · 端到端

- [ ] 外部经 nginx 访问 `/authserver/oauth/token` 返回 **401 + serial 头**
- [ ] 用真实账号可登录并拿到 token（`respStatus=200`）
- [ ] 登录后首页/病人列表可正常加载
- [ ] 关键业务接口（列表、详情、附件）各跑通 1 次
- [ ] 慢日志 Top20 中无"全表扫描级"条目
- [ ] 无持续 ERROR（连续 10 分钟为 0）

## 阶段 9 · 切流

- [ ] 停机窗口已确认并通知
- [ ] 回退演练完成（起旧容器 → 验证 → 再停）
- [ ] 旧容器 `stop`（**未 `rm`**）
- [ ] 最后一次增量 `rsync` 完成
- [ ] 切流后冒烟通过
- [ ] 旧机保持关机、不销毁，记录观察期截止日

---

## 附：三组必须留存的数字

| 类别 | 记录内容 | 用途 |
|---|---|---|
| 数据 | 每张大表的 `COUNT(*)`（源/目标） | 事后争议时的唯一证据 |
| 文件 | 每个目录的「文件数 + 字节总和」 | 同上 |
| 性能 | 慢日志 Top20（SQL + 耗时 + 扫描行数） | 观察期基线对比 |
